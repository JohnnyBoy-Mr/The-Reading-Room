**The Reading Room – Independent Bookstore Website**

A modern, responsive, single-page website for an independent bookstore, built using HTML5 and CSS3 without any frameworks. The website showcases a collection of fiction, nonfiction, and staff-recommended books, including book titles, authors, and prices. It also features an upcoming events section for book clubs and readings.

The website uses semantic HTML for accessibility, CSS Grid for book layouts, and Flexbox for navigation and content alignment. It is designed to provide a clean, user-friendly browsing experience across mobile, tablet, and desktop devices.
